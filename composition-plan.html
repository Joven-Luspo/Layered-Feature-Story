L6 · Composition Plan

Element Content purpose Normal-flow baseline Chosen technique and why Containing block / stacking context Fallback or disengagement Required test
Header issue badge (L3) Small editorial label that identifies the feature. Inline text after the byline in the header. Absolute positioning anchors the badge in the top-right corner of the header without moving the title or lede. .feature-header is position:relative and the named containing block. Badge uses layer token --layer-badge:3. At 52rem and below it returns to static flow below the byline. Long title, 320px width, 200% zoom; confirm no overlap with title or focus.
Story guide (L3) Navigation links to five story sections. Navigation appears before article in document order. Sticky positioning keeps navigation visible while reading on wide screens; Grid handles the page columns. Sticky element is bounded by the .page-layout grid item/container; nearest scrolling ancestor is the page. Uses --layer-sticky:2. At 52rem and below, position becomes static and the layout becomes one column. Scroll from page top through article end; verify it stops at its containing block. Test each anchor by pointer and keyboard.
Pull quote (L3–L4) Emphasizes the shift from arcade rounds to persistent home-game worlds. Blockquote sits between paragraphs in normal source order. Relative positioning is not needed; a negative block-start margin creates a controlled overlap with the preceding figure. Local z-index keeps it above the figure. Nearest positioned ancestor is the story section; --layer-raised:1. No global overlay context. At narrow widths the negative inline margin is removed; block margin is restored. Double preceding paragraph and quote text; inspect overlap, keyboard focus, and pointer access.
Feature image frame (L5) Decorative illustration introduces the arcade section. Figure and image remain full-width content in normal flow. Rounded frame and a polygon clip-path give the image a subtle editorial cut without clipping text or controls. Figure is position:relative for a named local frame; no z-index is applied to it. Base image remains rectangular if clip-path is unsupported or disabled. Caption remains outside clipped image. Disable clip-path in DevTools; verify full image and caption remain readable. Test image scaling at all viewport sizes.
Controller portrait (L5) Visual break beside the modern gaming section. Image is a block image between paragraphs with alt text. At wide widths it floats inline-start and uses shape-outside:circle(50%) with shape-margin to create an editorial wrap. Float and shape affect inline flow within the .modern-section block formatting context, established by display:flow-root. Shape rule is feature-queried. Below 48rem the image returns to a centered block; without shape support, the image returns to ordinary block flow. Disable shape-outside; confirm text remains in DOM order and image/paragraphs remain readable. Double paragraph length.
Rounded surfaces (L5) Visually groups guide, quote, image frame, and documentation panel. Each block is a regular rectangular box. Small consistent border radii provide grouping and visual hierarchy; they do not alter content geometry. Ordinary block formatting; no new stacking context intentionally created by radius. Square corners are a fully equivalent fallback. 200% zoom and high text zoom; confirm borders do not clip text or focus outlines.
Header decoration (L4) Subtle visual texture behind the header copy. Decorative circle would be absent. Absolutely positioned pseudo-element is bounded to the header and marked pointer-events:none so it cannot intercept interaction. .feature-header containing block; decorative pseudo-element is not assigned z-index. Decoration can disappear without affecting content or navigation. Click badge and header content; verify decorative area never blocks pointer activation.

Layer tokens: base 0, raised 1, sticky 2, badge 3. Values are deliberately small and semantic.
